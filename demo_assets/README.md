# Aletheia Demo Dataset

This dataset is designed specifically for demonstrating, benchmarking, and testing the Aletheia AI Media Provenance Framework. 

## Dataset Structure

- `ai/`: Contains subdirectories for images generated by various AI models (DALL-E, Gemini, Stable Diffusion XL, FLUX, Midjourney).
- `real/`: Intended for authentic, unmanipulated camera photographs.

## Image Sources and Licensing

To comply with licensing and copyright, we do not bundle unauthorized AI-generated images or proprietary photographs. Instead, we provide a helper script (`download_samples.py`) to fetch legally usable images:

### AI-Generated Images
- **Source:** Wikimedia Commons (Category: AI-generated images).
- **Generators:** DALL-E, Stable Diffusion, Midjourney, etc.
- **License:** Public Domain (CC0) or similar free licenses, as declared by uploaders on Wikimedia Commons.
- **Purpose:** To serve as positive samples (AI-generated) for Layer 2 (AI Forensics Engine) evaluation.

### Real Images
- **Source:** Lorem Picsum (sourced from Unsplash).
- **Generators:** N/A (Actual camera photography).
- **License:** Free to use (Unsplash License / CC0 equivalents for placeholders).
- **Purpose:** To serve as negative samples (Authentic) for Layer 2 evaluation, and as base images for embedding provenance in Layer 1.

## How to Add Your Own Camera Photos (Real Images)

While the download script fetches placeholder "real" images, the best way to demonstrate Aletheia is using your own camera photos:
1. Take authentic photos using your smartphone or digital camera.
2. Transfer the raw/original JPEG/PNG files to your computer.
3. Place them directly into the `demo_assets/real/` directory.
4. Run the validation script to ensure they are compatible.

## Included Scripts

### 1. Download Samples (`download_samples.py`)
Fetches sample images from public sources to populate the dataset automatically.
**Usage:**
```bash
cd demo_assets
python download_samples.py
```

### 2. Validate Dataset (`validate_dataset.py`)
Checks the integrity of the dataset. It verifies:
- Image format (PNG, JPG, JPEG, WEBP)
- Minimum resolution (e.g., at least 224x224)
- Exact file duplicates (using SHA-256 hashes)
- Corrupted files that cannot be opened by PIL

**Usage:**
```bash
cd demo_assets
python validate_dataset.py
```
